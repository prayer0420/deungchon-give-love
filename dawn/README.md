## 한 줄 설명

화면은 한 장으로 고정되어 있고, 스크롤을 내리거나 올리면 수천 개의 빛 입자가 모양을 바꿉니다.
밤에서 시작해 해가 뜨는 아침으로 끝나는 이야기입니다.

| 장면 | 입자가 만드는 모양 | 글 |
|---|---|---|
| 1 | 새생명축제 (글자) | 당신을 초대합니다 · 11월 15일 주일 오후 2시 30분 · 등촌교회 본당 |
| 2 | 11.15 (숫자) | 주일 오후 2시 30분 · 실시간 남은 시간 · 캘린더에 저장 |
| 3 | 열린 문 | 교회가 처음이어도, 오랜만이어도 괜찮아요 |
| 4 | 무언극 가면 | 말 없이, 몸짓으로 전하는 이야기 |
| 5 | 난타 북 | 힘차게 두드리는 리듬 공연 · 화면을 두드리면 북소리 |
| 6 | 리본을 묶은 선물 상자 | 처음 오신 분께 드리는 작은 선물 |
| 7 | 실제 등촌교회 건물 (여기서 아침이 됩니다) | 등촌교회 본당 · 주소 복사 · 네이버 지도 · 카카오맵 · 2청년회 소개 |
| 8 | 떠오르는 해 | 당신의 자리를 맡아 둘게요 · 갈게요 · 카카오톡 공유하기 |

## 파일

- index.html: 문구 전부. 자바스크립트가 꺼져 있으면 이 내용이 종이 초대장처럼 위에서 아래로 보입니다.
- assets/css/dawn.css: 화면 배치와 글꼴. 넓은 화면은 글이 왼쪽, 빛이 오른쪽입니다.
- assets/js/dawn.js: 입자 엔진(WebGL, 안 되면 2D 캔버스), 장면 색, 공유·캘린더·주소 복사·배경음악·갈게요.
- assets/img/map-mask.webp, map-church.webp: 입자 밀도 지도(RGB는 색, 알파는 입자가 모이는 정도). 교회 지도는 등촌교회 홈페이지의 건물 사진에서 만들었습니다.
- assets/img/og.jpg: 카카오톡 링크 미리보기(실제 표지 화면을 찍은 것).
- assets/fonts: Hahmlet 500·700(제목), Pretendard 400·600(본문), IBM Plex Mono 500(영문 라벨). 쓰는 글자만 남긴 파일입니다.

## 고칠 때

- 문구를 바꾸면 폰트 서브셋을 다시 만듭니다: tools/dawn_fonts.py (새 글자가 빠지면 기본 글꼴로 보입니다).
- 장면의 밤·낮 색은 dawn.js의 LOOK 표에 있습니다. 6번째 장면부터 낮(밝은 배경, 먹색 입자)입니다.
- 입자 모양: 글자는 textCanvas, 문·북·선물 상자·해는 doorCanvas·drumCanvas·giftCanvas·sunCanvas에서 캔버스에 그립니다. 가면은 tools/dawn_maps2.py, 교회 건물은 tools/dawn_church.py로 만든 이미지 지도입니다.
- 카카오톡 공유: 카카오 개발자 앱의 JavaScript 키를 dawn.js의 KAKAO_KEY에 넣으면 카카오톡 공유 창이 바로 열립니다. 키가 없으면 휴대폰 공유 시트, 컴퓨터는 링크 복사로 동작합니다.
- 확인: tools/dawn_probe.mjs (5가지 화면 × 8장면 배치, 겹침, 오류, 버튼, 동작 줄이기, 스크립트 끔).
- 미리보기 이미지: tools/dawn_og.mjs.
