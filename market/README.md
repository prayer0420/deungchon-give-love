# 기부 러브 플리마켓 웹 초청장 (/market/)

- 공개 주소: https://prayer0420.github.io/deungchon-give-love/market/
- 무엇: 2026년 11월 7일(토) 12:00–16:00 등촌교회 「기부 러브 플리마켓」 모바일 초청장. 확정 포스터를 다시 만든 v18 시안 4종의 디자인(흰 바탕이나 단색 바탕, 빨강 하나, Paperlogy 큰 글씨, 장면마다 그래픽 하나)을 화면으로 옮겼다.
- 동작: 화면 한 장이 고정되고, 휠·스와이프·방향키·아래 「다음」 버튼으로 장면 여섯 개가 제자리에서 바뀐다. 메인(/)의 새생명축제 초청장은 그대로 두고, 마지막 장면에서 그쪽으로 이어진다.

## 파일

- index.html, assets/css/market.css, assets/js/market.js
- assets/fonts: SUIT(가변), Paperlogy 800·900. 쓰인 글자만 남김(63KB, 16KB, 17KB), 모두 SIL OFL 1.1
- assets/img: og.jpg(링크 미리보기 1200×630), favicon.png, touch-icon.png
- assets/market.ics: 캘린더 파일(애플 기기). 다른 기기는 구글 캘린더 링크로 바뀜
- og.html, icon.html: 위 이미지의 원본(배포하지 않음)

작업 폴더 C:/Users/c/IdeaProjects/ai-workspace 에서:
