## 만든 방법

- 줄무늬 차양은 그림이 아니라 CSS repeating-linear-gradient 줄무늬와 radial-gradient 반원 두 겹이라 화면 폭이 달라도 줄 폭이 같다.
- 전구 · 깃발 줄은 1600u 폭 SVG 하나를 가운데에 두고 화면 밖은 잘리게 했다. 가운데에서 떨어진 거리(--i)를 켜지는 순서로 써서 가운데부터 퍼진다.
- 표지의 크림색 땅은 부스 그림의 지평선(그림 높이 86.6%)에서 시작하는 ::before라 화면 높이가 달라도 부스가 늘 땅 위에 선다. .sc-in에 isolation:isolate를 줘야 z-index:-1이 장면 바탕 뒤로 숨지 않는다.
- 부스 그림과 잎은 v17 포스터의 v17_art.mjs를 그대로 import하고 C 팔레트만 CSS로 입혔다.
- 이탤릭 GIVE · LOVE는 SVG text에 paint-order:stroke로 종이색 테두리를 줘서 한글 모서리에 걸쳐도 엉키지 않는다.
- SVG 안에서 CSS transform을 쓰는 조각은 transform-box:fill-box로 기준점을 잡는다. 잎처럼 transform 속성으로 놓인 것은 바깥 g에만 애니메이션을 건다(같은 요소에 걸면 위치가 덮어써진다).
- Archivo · Fraunces는 varLib.instancer로 900 한 굵기 정적 글꼴로 자른 뒤 subset해서 185KB · 230KB가 8KB · 13KB가 됐다.
- 절대 위치 SVG에는 height:auto를 꼭 준다. 빠지면 부모 높이로 늘어나 viewBox 내용이 세로 가운데로 내려간다(링크 미리보기의 전구 줄에서 겪음).
- 상자 덮개 접기: 열린 덮개를 경첩 선으로 납작하게 접고(scale → 0), 같은 경첩에서 닫힌 덮개를 펼친다(0 → 1). 두 모양이 경첩에서 한 줄이 되는 순간에 바뀌어 하나의 덮개가 넘어가는 것처럼 보인다.
- 비스듬한 경첩: 옆 덮개는 matrix(1 0 -1.4 1 0 0)로 기울인 그룹 안에 그려 그룹 안에서는 경첩이 세로선이 되게 했다. 그래서 transform-box:fill-box의 100% · 0% 기준점과 scaleX만으로 기울어진 경첩을 따라 접힌다.
- 물건이 하트로 바뀌는 것은 카드 뒤집기다. 아이콘이 scaleX 1 → 0으로 접히는 순간 하트가 scaleX 0 → 1.14 → 1로 펼쳐진다. 날아가는 움직임은 바깥 g(translate), 뒤집기는 안쪽 g(scale)로 나눠 transform이 서로 덮어쓰지 않게 했다.
- 멈춘 화면이 마지막 모습이 되도록 기본 스타일을 끝 상태(닫힌 상자 · 꼬리표)로 두고, 애니메이션은 fill-mode both로 시작 상태를 덮어쓴다. 동작 줄이기와 자바스크립트 꺼짐에서 따로 손댈 것이 없다.
- 프레임 확인: 모든 애니메이션을 pause하고 currentTime을 맞춰 찍으면(market2_s4frames.mjs) 화면 녹화 없이도 시점별 모습을 정확히 볼 수 있다. 다시보기도 같은 API로 currentTime = 0, play().
