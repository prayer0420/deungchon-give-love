- 동작 줄이기 설정을 켠 기기는 짧은 페이드로만 바뀝니다. 자바스크립트가 꺼져 있으면 모든 장면이 아래로 이어진 일반 페이지로 보입니다.

## 글자가 겹치지 않게 지키는 규칙

- 표지 제목 크기는 화면 높이에서 날짜 정보 자리를 먼저 빼고 남은 높이로 정합니다. 그래서 1280×720이나 1366×625 같은 낮은 노트북 화면에서도 날짜가 LOVE를 덮지 않습니다.
- 세로 휴대폰은 두 가지로 배치합니다. 세로가 가로의 1.8배 이상이면 제목을 위에 크게 두고 가격표를 LOVE 아래에 겁니다. 그보다 짧으면 제목 옆에 걸되, 가격표가 2.2도 흔들린 끝에서도 글자와 14px 이상 떨어지도록 제목 폭과 가격표 폭을 함께 계산합니다(`app.css`의 `--cvF`, `--hw`, `--hx`).
- 가로로 눕힌 휴대폰은 날짜 정보를 제목 옆으로 옮깁니다.
- 표지로 돌아올 때 가격표는 오른쪽으로 둘러 내려와 LOVE 뒤를 지나가지 않습니다.
- 큰 영문·숫자(Bricolage 75% 폭)는 자간을 0 이상으로 둡니다. 음수로 두면 11.15 같은 숫자가 서로 붙습니다. 한글 제목은 -0.03em 정도가 알맞습니다.
