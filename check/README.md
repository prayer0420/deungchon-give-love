## 한 줄 설명

"교회는 처음이면 어색할 것 같죠?"라는 질문과 걱정 목록 여섯 칸으로 시작하는 설명 영상형 초대장입니다. 스크롤할 때마다 프로그램이 걱정을 하나씩 지우고, 마지막에는 같은 목록이 다 지워진 채로 다시 나오고 「갈게요」 한 칸이 남습니다.
오.AI.완에 소개된 클로드 모션 그래픽 프롬프트(질문, 모델, 증명, 반전, 답 / 살아 있는 물체 하나 / 렌더 계약)를 초대장에 맞게 옮겼습니다.

| 단계 | 화면 | 지워지는 걱정 → 답 |
|---|---|---|
| 1 질문 | 「교회는 처음이면 어색할 것 같죠?」와 빈 걱정 목록 | |
| 2 모델 | 일정표: 날짜, 시간, 장소, 프로그램, 남은 시간 | |
| 3 무언극 | 가면 사진 (누르면 클로즈업) | 성경, 교회 용어 → 무언극은 말이 없어요 |
| 4 난타 | 북 두 개 여덟 박 리듬 예시 (누르면 소리) | 찬양 가사 → 난타는 듣기만 해요 |
| 5 웰컴키트 | 선물 사진 (누르면 For you 태그) | 준비물 → 선물은 저희가 드려요 |
| 6 2청년회 | 2026년 11월 달력: 주일마다 점, 15일은 파란 원 | 아는 사람 → 2청년회가 맞이해요 |
| 7 본당 | 등촌교회 선 그림과 주소 (누르면 종소리) | 앉을 자리 → 자리를 맡아 둘게요 |
| 8 반전 | 처음이에요 · 오랜만이에요 · 다니고 있어요 (눌러서 바꿔 보기) | 교회 다녀 본 경험 → 처음이어도 괜찮아요 |
| 9 답 | 다 지워진 목록, 「갈게요」, 캘린더, 카카오톡 공유, 지도 | |

목록의 칸을 누르면 그 걱정을 지우는 단계로 바로 갑니다.

## 파일

- index.html: 문구 전부. 자바스크립트가 꺼져 있으면 단계가 위에서 아래로 이어지고, 목록은 다 지워진 상태로 보입니다.
- assets/css/check.css: 배치와 글꼴. 휴대폰은 목록이 위, 설명이 아래. 넓은 화면은 설명이 왼쪽, 목록이 오른쪽입니다.
- assets/js/check.js: TIMELINE(단계별로 가르치는 것, 지우는 걱정, 움직임 구간), paint(t), 소리, 공유·캘린더·주소 복사·갈게요·남은 시간.
- assets/fonts: Hahmlet 700, IBM Plex Sans KR 400·500·600 (둘 다 OFL). 쓰는 글자만 남긴 파일입니다.
- directions.html: 방향 네 가지와 결정 기록. DECISIONS.md: 결정 한 줄씩.

## 고칠 때

- 문구를 바꾸면 폰트 서브셋을 다시 만듭니다: tools/check_fonts.py.
- 걱정과 답은 index.html의 .cell 여섯 개입니다. data-go가 그 걱정을 지우는 단계 번호입니다.
- 움직임 구간은 check.js의 TIMELINE.move(나가기, 목록 이동, 그림, 글, 지우기)에서 한꺼번에 바꿉니다.
- 렌더 계약: 브라우저 콘솔에서 seek(4.5)처럼 부르면 그 순간을 그대로 그립니다. seek(null)이면 스크롤로 돌아갑니다.
- 카카오톡 공유: KAKAO_KEY에 카카오 개발자 앱의 JavaScript 키를 넣으면 공유 창이 바로 열립니다. 키가 없으면 휴대폰 공유 시트, 컴퓨터는 링크 복사입니다.
