# 모션 포스터 · 디자인 노트

## 방향

세 번째 버전(/open/)은 물건 속으로 카메라가 날아 들어가서 화면 전체가 계속 확대됐고, 그래서 어지러웠습니다. 이번에는 jitter.video의 템플릿을 참고해 반대로 갔습니다. 화면은 포스터처럼 가만히 있고, 바뀌는 것은 포스터 자체입니다.

jitter 템플릿에서 가져온 규칙입니다.

- 카메라는 움직이지 않습니다. 글자와 사진은 마스크(잘린 틀) 안에서 나타납니다.
- 바탕색은 서서히 바뀌지 않고 딱 끊어서 바뀝니다(흰색, 빨강, 검정, 회색).
- 강조색은 한 가지입니다. 여기서는 붉은 점의 #d83a1f.
- 작은 고정폭 라벨(NEW LIFE FESTIVAL, SAVE THE DATE, PROGRAM)과 양옆의 십자 표시가 화면을 잡아 줍니다.
- 움직임은 빠르게 시작해 부드럽게 멈춥니다(expo out). 잠깐 멈췄다 다시 움직이는 박자가 있고, 멈춘 화면에서는 아무것도 저절로 흔들리지 않습니다.

템플릿별로 빌린 장면입니다.

- 「To be the best」 단어가 하나씩 쌓이는 문장 → 2 초대
- 「ACME FW24」 작은 사진이 세 번 끊어 커짐 → 4 무언극
- 「Status: New PR」 데이터 줄과 같은 문장을 여러 줄 반복 → 3 날짜의 데이터 줄, 5 난타의 네 줄
- 「Curation」 사진이 아래에서 밀려 올라옴 → 4 무언극의 클로즈업, 6 웰컴키트
- 마지막 장면의 가는 선 로고 → 7 등촌교회 선 그림

## 색

- 흰색 #ffffff, 회색 #ecebe8, 검정 #0f0e10, 글자 #18171b
- 빨강 #d83a1f 하나. 흰 글씨와의 대비가 4.6:1이라 작은 글씨도 읽힙니다. 처음 고른 #e8462a는 3.9:1이라 작은 글씨 기준에 못 미쳐서 조금 깊게 바꿨습니다.

## 글꼴

- 제목: Pretendard 800, 아주 크게, 자간 -0.045em.
- 본문: Pretendard 400과 600.
- 라벨과 숫자 데이터: Geist Mono 500, 대문자, 자간 0.05em. 한글이 섞이면 Pretendard로 넘어갑니다.

## 붉은 점

점은 둥근 막대 두 개입니다. 두 막대가 같은 크기로 겹치면 원이고, 세로와 가로로 벌리면 십자가, 등받이와 방석 크기로 바꾸면 의자입니다. 위치, 너비, 높이, 둥근 정도 다섯 숫자만 섞으면 모양이 바뀌어서 따로 모핑 라이브러리가 필요 없습니다.

- 표지 → 초대: 해가 지평선을 완전히 벗어날 때까지 떠오른 뒤, 이동하는 것보다 빨리 작아져서 마침표 크기로 문장 끝에 앉습니다.
- 초대 → 날짜: 마침표가 커지기 시작해 화면 절반을 지날 때 화면 대각선 반지름이 됩니다. 날짜 장면은 바탕이 없고 이 원이 바탕입니다.
- 날짜 → 무언극: 빨강이 오그라들며 프로그램 목록 첫 칸으로 빨려 들어갑니다. 원 밖은 다음 장면의 검정이 보이게, 원 아래 바탕은 이웃 장면 색을 씁니다.
- 프로그램 세 장: 목록은 제자리에 있고 점만 한 칸씩 내려갑니다(가는 동안 살짝 늘어남). 바탕은 검정, 회색, 검정으로 끊어 바뀝니다.
- 웰컴키트 → 오시는 길: 점이 탑으로 날아가 십자가로 벌어집니다.
- 오시는 길 → 자리: 십자가의 세로가 등받이, 가로가 방석이 되며 C열 6번 의자에 앉습니다. 의자 다리는 도착 직전에 나타납니다.

## 움직임 규칙

- 스크롤과 직접 묶인 것은 붉은 점과 맨 위 진행 막대뿐입니다. 손가락을 끄는 동안에도 점이 따라와서 반응이 바로 보입니다.
- 나머지는 시간으로 움직입니다. 장면이 바뀌는 순간 .in 클래스가 붙고, CSS 전환이 정해진 지연(--d)을 두고 차례로 재생됩니다. 스크롤 속도와 관계없이 늘 같은 모션 그래픽으로 보입니다.
- 장면은 두 장면 사이의 가운데(0.52, 깜빡임 방지 여유 포함)에서 끊어 바뀝니다. 떠나는 장면은 그 순간 바로 사라져서 두 장면의 글이 겹쳐 보이지 않습니다.
- 끄는 동안 떠나는 장면은 16px 들리며 조금 흐려지고, 들어오는 장면은 제자리로 내려앉습니다. 화면 전체 확대나 이동은 없습니다.

## 접근성과 예외

- 동작 줄이기: 등장 효과 없이 바로 보이고, 점도 장면마다 제자리로 바로 옮겨 갑니다.
- 자바스크립트가 꺼져 있으면 여덟 장이 바탕색 띠로 이어지고, 해와 마침표와 십자가와 빨간 의자는 그림으로 그려져 있습니다.
- 효과음은 사용자가 화면을 누른 뒤에만 납니다.

## 이번에 쓴 기법과 팁

1. 마스크 줄: .m에 overflow:hidden을 주고 위아래 패딩(0.08em, 0.14em)과 같은 크기의 음수 마진을 함께 줍니다. 한글 받침과 쉼표가 잘리지 않고 배치는 그대로입니다. 안쪽 .mi를 translateY(120%)에서 0으로 올립니다.
2. 끊어 바꾸기: 떠나는 장면에 cut 클래스(전환 끔)를 붙이고 .in을 뗀 뒤 offsetWidth를 한 번 읽고 cut을 뗍니다. 숨김 상태로 즉시 돌아가서 다음에 들어올 때 처음부터 재생됩니다. .in은 requestAnimationFrame 두 번 뒤에 붙여야 시작 상태가 먼저 그려집니다.
3. 점이 멈출 자리는 등장 효과를 끈 상태(html.measure)에서 getBoundingClientRect로 잽니다. 움직이는 중간 위치가 아니라 최종 배치를 기준으로 하고, 글꼴이 로드된 뒤(document.fonts.ready)와 화면 크기가 바뀔 때 다시 잽니다.
4. 큰 원으로 화면 덮기: 반지름을 화면 대각선의 절반보다 조금 크게 잡고 중심을 화면 가운데로 옮기면 어느 비율의 화면이든 다 덮입니다. 반지름은 처음엔 천천히, 나중에 빠르게(세제곱 가속) 키워야 마침표가 부푸는 느낌이 납니다.
5. 크기와 위치의 속도를 따로 줍니다. 큰 해가 문장으로 날아올 때 크기를 먼저 줄이지 않으면 큰 원이 글자를 덮고 지나갑니다.
6. 숫자 카운터: 자리마다 마지막 숫자 너비의 틀(보이지 않는 같은 숫자로 너비를 잡음)을 만들고, 그 안에 숫자 띠를 left:50%와 translateX(-50%)로 가운데 맞춥니다. 자리마다 띠 길이를 다르게 하면 서로 다른 순간에 멈춰서 기계 같지 않습니다.
7. 계단식 확대(ACME): 키프레임 두 개에 같은 값을 두면 멈춤이 되고, 구간마다 animation-timing-function을 따로 줍니다.
8. 계단 배치: container-type:inline-size를 준 부모 안에서 translate: calc(i / 3 * (100cqw - 100%)) 0. 마지막 줄이 정확히 오른쪽 끝에 붙습니다.
9. 선 그리기: path와 rect에 pathLength="1"을 주고 stroke-dasharray 1 1, stroke-dashoffset 1에서 0으로 바꿉니다. 길이를 몰라도 모든 선이 같은 시간에 그려집니다.
10. 단어 나누기는 일반 공백, 탭, 줄바꿈에서만 합니다. \s로 나누면 &nbsp;까지 쪼개집니다. 마지막 단어와 마침표 자리는 nowrap으로 묶어야 점이 혼자 다음 줄로 넘어가지 않습니다.
11. 검증: 장면마다 레이아웃 조각끼리의 겹침, 머리말과 바닥 표시 침범, 화면 밖 넘침을 숫자로 봅니다. 멈춤 검사는 1.2초 간격 스크린샷 두 장을 바이트로 비교하고, 다르면 픽셀 차이 범위를 봅니다. 이번에는 남은 시간 초 숫자만 바뀌었습니다.
