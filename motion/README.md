## 한 줄 설명

jitter.video의 모션 템플릿처럼 만든 포스터 여덟 장입니다. 카메라는 움직이지 않습니다. 스크롤하면 포스터가 딱 끊기며 바뀌고, 새 포스터는 글자와 사진이 마스크 안에서 짧게 올라오며 완성됩니다.
스크롤을 따라 움직이는 것은 붉은 점 하나뿐입니다. 이 점이 해, 마침표, 날짜 화면의 빨간 바탕, 프로그램 목록의 선택 표시, 교회 십자가, 마지막의 의자로 차례로 바뀝니다.

## 파일

- index.html: 문구 전부. 자바스크립트가 꺼져 있으면 포스터 여덟 장이 바탕색 띠로 위에서 아래로 읽힙니다.
- assets/css/motion.css: 배치, 글꼴, 등장 효과(마스크, 계단식 확대, 아래에서 여는 사진, 선 그리기, 숫자 굴리기). 넓은 화면은 두 칸입니다.
- assets/js/motion.js: 장면 전환(가운데 지점에서 끊기), 붉은 점, 장면별 반응과 효과음, 공유·캘린더·주소 복사·배경음악·갈게요·남은 시간.
- assets/fonts: Pretendard 400·600·800, Geist Mono 500 (둘 다 OFL). 쓰는 글자만 남긴 파일입니다.
- assets/img: 가면(mask.webp), 선물(gift.webp), 카카오톡 미리보기(og.jpg, 실제 표지 화면).

## 고칠 때

- 문구를 바꾸면 폰트 서브셋을 다시 만듭니다: tools/motion_fonts.py.
- 장면 색은 index.html의 data-tone(w 흰색, g 회색, r 빨강, k 검정)입니다. 빨강 장면은 바탕이 없고 붉은 점이 화면을 덮습니다.
- 붉은 점이 멈추는 곳은 화면 안의 표식으로 정합니다. #sunArt(해), #aPeriod(마침표), #pidx .mk(목록), #crossV와 #crossH(십자가), #seatBack과 #seatBase(의자). 위치를 옮기면 점도 따라옵니다.
- 장면 사이 점의 움직임은 motion.js의 dotState 안에 장면 번호별로 있습니다.
- 카카오톡 공유: KAKAO_KEY에 카카오 개발자 앱의 JavaScript 키를 넣으면 공유 창이 바로 열립니다. 키가 없으면 휴대폰 공유 시트, 컴퓨터는 링크 복사입니다.
- 확인: tools/motion_probe.mjs. 5가지 화면 × 8장면의 겹침과 넘침, 붉은 점 위치, 장면 사이 프레임, 장면별 누르기, 멈춘 화면 비교, 동작 줄이기, 스크립트 끔을 봅니다. 미리보기 이미지는 tools/motion_og.mjs로 만듭니다.
